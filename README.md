# Responsive Product Pricing Cards

A three-plan SaaS pricing section with a Monthly/Yearly toggle, a highlighted Popular plan, ribbons and hover effects.

## Features
- Monthly/Yearly switch (JavaScript, `aria-pressed`)
- Popular and Best Value ribbons
- CSS Grid layout, hover lift with transitions and transforms
- Responsive: single column below 800px, Popular plan first
- Keyboard focus styles, reduced-motion support, contrast 4.5:1 or higher

## Files
- `index.html` - page structure
- `style.css` - styling
- `script.js` - billing toggle

## Run
Open `index.html` in VS Code with Live Server.

Prices are made up. Yearly prices are about 20 percent cheaper than 12 months of monthly billing.
